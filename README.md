# EMBER TRACE
### ATHERION Earth — NASA Space Apps Challenge 2026

**Challenge:** Harmonization of MODIS and VIIRS Hot Spots

## Overview

EMBER TRACE is a conceptual project that explores how historical thermal anomaly observations from NASA's MODIS and VIIRS satellite instruments could be compared and interpreted through a unified, accessible platform.

The project focuses on Argentina and aims to help users explore historical hotspot observations, understand differences between satellite sensors, and gain a clearer temporal and spatial perspective on thermal activity.

## The Problem

MODIS and VIIRS provide valuable satellite observations of thermal anomalies. However, differences in sensor characteristics, spatial resolution, observation times, and data products can make direct comparisons challenging.

A thermal anomaly detection should not automatically be interpreted as a confirmed wildfire.

EMBER TRACE addresses this challenge through a proposed approach centered on data comparison, context, and transparency.

## Our Proposed Solution

We propose a platform featuring:

- An interactive map for exploring thermal anomaly observations.
- Historical and temporal filters.
- Side-by-side MODIS and VIIRS comparisons.
- Statistical summaries of observations.
- Clear explanations of sensor differences and data limitations.
- Data source references and methodological transparency.

These features represent the proposed project design, not a fully implemented software application.

## NASA Data Sources

The project concept is based on publicly available NASA resources:

- [NASA FIRMS](https://firms.modaps.eosdis.nasa.gov/)
- [NASA Earthdata](https://earthdata.nasa.gov/)
- [VIIRS Fire Earth Science Data Record](https://viirsland.gsfc.nasa.gov/Products/NASA/FireESDR.html)

These resources provide the scientific and technical foundation for the proposed exploration and comparison workflow.

## Development Status

During NASA Space Apps Challenge 2026, our team focused on developing the project concept, defining its proposed functionality, and preparing its visual and presentation materials.

**No software implementation or new application code was developed during the hackathon.**

EMBER TRACE is presented as a conceptual solution and design proposal. The platform's described features should not be interpreted as currently operational functionality.

## Scientific Considerations

EMBER TRACE emphasizes responsible interpretation of satellite observations:

- A thermal anomaly detection does not necessarily confirm a fire.
- MODIS and VIIRS observations must retain their individual sensor characteristics.
- Confidence values and Fire Radiative Power (FRP) are different measurements and should not be treated as equivalent.
- Data sources, limitations, and methodology should remain transparent.
